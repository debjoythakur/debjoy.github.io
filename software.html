Research Code Repositories

The following repositories provide code and computational material related to selected research projects.

R · Spatial Point Processes

Multi-Resolution Variable Selection

Reproducible code for multiresolution variable selection in spatial point-process intensity models, motivated by crime and traffic-related spatial event data in St. Louis.

The project investigates spatially heterogeneous predictor effects using localized basis representations and penalized variable-selection methods.

View Repository →
R · Local Variable Selection

Local Variable & Neighborhood Selection

Research code for localized variable and neighborhood selection in spatial firearm-fatality data from the southeastern United States.

The project develops spatially adaptive variable-selection methodology for identifying geographically varying associations and local neighborhood effects.

View Repository →
R · Variational Inference

Variational REML for Spatial Data

Code associated with variational restricted maximum likelihood estimation for Gaussian spatial models with intrinsic conditional autoregressive structure.

The repository contains methodology and computational implementation related to scalable variational approximation and spatial random-effects estimation.
